# markcount

粘贴或打开 Markdown，实时渲染，只统计真正的字。纯静态页面，文件只在浏览器里读取，不会上传。

## 用法

- **编辑器**：左边输入或粘贴 Markdown，右边实时渲染，底部显示总字数，以及汉字、词、字符的明细。草稿保存在本机浏览器里。
- **本地仓库**：选择一个 Obsidian 仓库文件夹，每篇笔记各得一个字数，可以排序、按路径筛选，点一行就在右边阅读。

## 统计规则

- 汉字、平假名、片假名逐字计；英文等其他文字按词计，`don't` 和 `well-known` 各算一个词。
- 不计：`#`、`**`、`---`、列表符号、链接和图片地址、HTML 标签、`$$公式$$`、围栏本身。
- 链接只计链接文字，`[[双链|别名]]` 只计别名（没有别名就计名字）。
- 默认不计文件头部的属性块（frontmatter）和 `%%注释%%`、`<!-- 注释 -->`；代码块和行内代码默认计入。三项都可以在页面右上角「统计范围」里切换。

## 打开 Obsidian 仓库

- 桌面版 Chrome 和 Edge：点「选择仓库文件夹」，浏览器会请求只读权限。
- 其他浏览器：自动改用文件夹选择。浏览器可能提示「上传」，实际只是在本机读取，没有任何网络请求。
- 以 `.` 开头的文件夹和文件（`.obsidian`、`.git`、`.trash`）会被跳过，只读取 `.md` 和 `.markdown`。
- 每次打开都要重新选择文件夹，页面不会记住仓库。

## 已知限制

- 手机上还没有实机测试。Android 的 Chrome 没有目录选择器，走备用入口；iOS 能不能选到 Obsidian 的仓库，取决于仓库存放的位置。
- 仓库很大时（几千篇）首次读取需要几秒，页面会显示进度。
- 笔记里的双链只显示名字，不会跳转。
